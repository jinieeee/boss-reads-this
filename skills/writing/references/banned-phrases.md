# 금지 표현

`scripts/check.py`가 이 파일의 표를 읽어서 검사한다. 첫 열에 백틱으로 감싼 문자열이 검사 대상이다. 표에 줄을 더하면 스크립트도 바로 그 표현을 잡는다.

- 첫 열은 글자 그대로 찾는다(정규식 아님).
- 띄어쓰기까지 맞아야 잡힌다. 자주 쓰는 띄어쓰기 변형은 줄을 따로 둔다.

## AI 관용구

| 표현 | 고치는 법 |
|---|---|
| `결론적으로` | 빼고 결론을 바로 쓴다 |
| `요약하자면` | 빼고 바로 쓴다 |
| `종합적으로` | 빼거나 무엇을 합쳤는지 쓴다 |
| `시사하는 바가 크다` | 무엇을 알게 됐는지 직접 쓴다 |
| `시사하는 바가 큽니다` | 무엇을 알게 됐는지 직접 쓴다 |
| `시사점` | 알게 된 점, 할 일 |
| `라고 할 수 있다` | "~이다"로 단정한다 |
| `라고 할 수 있습니다` | "~입니다"로 단정한다 |
| `주목할 만하다` | 왜 중요한지 쓴다. 근거 수치가 있으면 수치로 |
| `주목할 만한` | 왜 중요한지 쓴다. 근거 수치가 있으면 수치로 |
| `중요한 역할을` | 무엇을 하는지 동사로 쓴다 |
| `핵심적인 역할` | 무엇을 하는지 동사로 쓴다 |
| `살펴보겠습니다` | 빼고 본론부터 쓴다 |
| `알아보겠습니다` | 빼고 본론부터 쓴다 |
| `단순히` | "A가 아니라 B" 구문이면 B만 쓴다 |
| `뿐만 아니라` | 문장을 둘로 나눈다 |
| `나아가` | 빼거나 "또"로 |
| `여정` | 과정, 기간 |
| `혁신적인` | 무엇이 달라졌는지 쓴다 |
| `획기적인` | 무엇이 달라졌는지 쓴다 |
| `극대화` | 늘린다. 목표치가 있을 때만 수치로 |
| `다각도로` | 어떤 관점에서 봤는지 쓴다 |
| `에 대한 깊은 이해` | 무엇을 아는지 쓴다 |
| `한 단계 더` | 빼거나 구체적으로 |
| `보장합니다` | 근거가 있을 때만. 아니면 "~하도록 합니다" |
| `—` | 쉼표나 마침표로 끊는다 |

## 블로그·홍보식 제목

웹 글과 홍보물에서 온 제목이다. 보고서, 발표 자료, 컨플루언스 페이지의 제목은 담긴 내용을 명사로 짓는다.

| 표현 | 고치는 법 |
|---|---|
| `한눈에 보기` | 요약, 개요, 현황 |
| `한눈에 보는` | 빼고 내용을 쓴다. "한눈에 보는 배포 절차"는 "배포 절차" |
| `총정리` | 정리, 개요. 범위가 있으면 "○○ 전체 목록" |
| `의 모든 것` | 다루는 범위를 쓴다. "○○ 개념과 설정" |
| `완벽 가이드` | 가이드, 사용 가이드 |

## 어려운 단어

| 표현 | 고치는 법 |
|---|---|
| `활용하` | 쓰- |
| `도모` | 꾀하다, 하다 |
| `제고` | 높이다 |
| `원활한` | 막힘없는, 또는 빼기 |
| `원활하게` | 막힘없이, 또는 빼기 |
| `다양한` | 여러, 또는 실제 목록 |
| `효과적으로` | 빼거나 어떤 효과인지 쓴다 |
| `효율적으로` | 무엇이 얼마나 줄었는지 |
| `최적화` | 무엇을 어떻게 바꿨는지 |
| `레버리지` | 이용하다 |
| `인사이트` | 알게 된 점 |
| `시너지` | 함께해서 생기는 효과를 구체적으로 |
| `니즈` | 필요, 요구 |
| `해당 ` | 이, 그 |

## 번역투

| 표현 | 고치는 법 |
|---|---|
| `에 대해` | 빼거나 "~을/를" |
| `에 대한` | 빼거나 "~의" |
| `을 통해` | ~로, ~해서 |
| `를 통해` | ~로, ~해서 |
| `에 있어서` | ~에서, ~할 때 |
| `에 있어` | ~에서, ~할 때 |
| `하는 것이 필요하다` | 해야 한다 |
| `하는 것이 필요합니다` | 해야 합니다 |
| `할 필요가 있다` | 해야 한다 |
| `할 필요가 있습니다` | 해야 합니다 |
| `를 가졌` | 회의했다, 했다 |
| `을 가졌` | 했다 |
| `로부터` | ~에게서, ~에서 |
| `으로부터` | ~에게서, ~에서 |
| `만약 ` | 빼고 "~하면" |
| `그것은` | 빼거나 가리키는 대상을 쓴다 |
| `에 의해` | 행위자를 주어로 |
| `에 의한` | ~ 때문에, ~가 낸 |
| `중 하나이다` | 빼고 단정 |
| `중 하나입니다` | 빼고 단정 |
| `수행하` | 하다 |
| `진행하였` | 했다 |

## 피동 표현

| 표현 | 고치는 법 |
|---|---|
| `되어지` | 되- (이중 피동) |
| `되어집니다` | 됩니다 |
| `보여지` | 보이- |
| `보여집니다` | 보입니다 |
| `생각되어` | 생각합니다 |
| `판단됩니다` | 판단합니다, 봅니다 |
| `예상됩니다` | 예상합니다, 행위자를 주어로 |
| `진행되었` | 누가 무엇을 했는지 쓴다 |
| `진행됩니다` | 누가 무엇을 하는지 쓴다 |
| `이루어졌` | 실제 동작을 쓴 동사로 |
| `이루어집니다` | 실제 동작을 쓴 동사로 |
| `게 되었습니다` | ~했습니다 |
| `게 되었다` | ~했다 |
